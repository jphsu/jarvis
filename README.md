# jarvis

A voice-first AI system that converts spoken thoughts into structured actions, reminders, notes, and calendar events.

## Current Features
- Text input interface
- Intent classification pipeline
- Structured output generation
- Persistent storage

## Planned Features
- Voice recording
- Speech-to-text transcription
- Google Calendar integration
- Long-term memory retrieval
- Daily summaries and proactive reminders

## Tech Stack
- Python
- Flask
- JavaScript
- Future LLM integration
